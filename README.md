# SCM-002 庫存語音查詢

以 **CSV / Excel** 為資料源的單頁 Web 應用，支援**語音與文字查詢**，依「目前庫存、安全庫存、日均用量」計算補貨建議。

## 快速開始

```powershell
cd D:\SCM-002
python -m http.server 8080
```

瀏覽器開啟：<http://localhost:8080/scm-voice-query.html>

> 直接雙擊 HTML 時，請用畫面「選擇檔案」手動載入 `SCM-002.csv`（瀏覽器安全限制無法自動讀取本機檔案）。
