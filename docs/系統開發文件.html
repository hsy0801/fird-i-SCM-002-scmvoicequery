1. 專案概述

供應鏈人員以語音或文字查詢庫存，依目前庫存、安全庫存、日均用量取得補貨建議。

目標

項目說明
資料匯入CSV、xlsx/xls，表頭自動對應
補貨建議建議補量、可用天數、風險標示
查詢文字、快捷問題、語音 zh-TW
模糊篩選品項、供應商可疊加意圖篩選
即時參數覆蓋天數變更立即重算

非目標

  • 無後端、無登入、不寫回 ERP／TIPTOP
  • Excel 僅第一個工作表
  • SheetJS 需 CDN（air-gap 需改本地）

3. 資料規格

一列 = 品項 × 供應商（可空）之庫存快照。

欄位必填說明
品項建議空白 → (未命名)
目前庫存是數值
安全庫存是數值
日均用量是數值
供應商否可空白

表頭支援中英文別名（COL + pickCol）。缺三項數值欄位則載入失敗。

4. 補貨與風險

參數預設範圍
建議覆蓋天數 #coverDays71～90
target      = safety + daily × coverDays
suggest     = max(0, ceil(target - stock))
daysLeft    = daily > 0 ? stock / daily : …
belowSafety = stock < safety
lowCover    = daily > 0 且 daysLeft < coverDays
needReorder = suggest > 0 且 (belowSafety 或 lowCover)
風險條件
低於安全庫存stock < safety
可用天數不足daysLeft < coverDays
正常其餘
flowchart TD
  A[載入 row] --> B[計算 suggest]
  B --> C{stock < safety?}
  C -->|是| D[低於安全庫存]
  C -->|否| E{天數不足?}
  E -->|是| F[可用天數不足]
  E -->|否| G[正常]

5. 查詢引擎

runQuery → parseIntent → analyzeRow 全列 → 意圖篩選 → 模糊篩選 → 排序 → renderResults
mode觸發篩選
reorder補多少／該補／空查詢needReorder
below_safety安全庫存belowSafety
low_days天數不足lowCover
all全部／列出不額外過濾
search僅關鍵字模糊 only

模糊：每個 term 須命中品項或供應商（AND）。含子字串與子序列匹配。

查詢範例結果
哪些品項該補多少需補貨列
益昌 布丁模糊命中列
益昌 布丁該補多少需補貨 + 模糊
